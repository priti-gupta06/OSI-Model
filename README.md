# OSI-Model
study the seven layers of the OSI model and map common protocols to each layer.


 Overview :

This project explains the seven layers of the OSI (Open Systems Interconnection) model and maps common network protocols to each layer.

Objective :

To understand network communication architecture and learn how data travels between devices over a network.

The Seven Layers of the OSI Model :

1. Application Layer (Layer 7): Provides network services to applications. Examples: HTTP, HTTPS, DNS, SMTP.
2. Presentation Layer (Layer 6): Handles data formatting, encryption, and compression concepts. Examples: JPEG, ASCII.
3. Session Layer (Layer 5): Establishes and manages communication sessions. Examples: RPC, NetBIOS session services.
4. Transport Layer (Layer 4): Provides end-to-end data delivery. Examples: TCP, UDP.
5. Network Layer (Layer 3): Handles logical addressing and routing. Example: IP.
6. Data Link Layer (Layer 2): Handles frames and MAC addresses on a local network. Example: Ethernet.
7. Physical Layer (Layer 1): Transmits raw bits through cables, fiber, or wireless signals.

Interview Questions :

1. What is the OSI model?
The OSI model is a seven-layer reference model used to understand network communication.

2. Which layer uses IP?
The Network layer (Layer 3).

3. Which layer uses TCP?
The Transport layer (Layer 4).

- Understood the difference between IP, TCP, HTTP, and Ethernet.
